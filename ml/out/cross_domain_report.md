# 跨域泛化对照实验报告

> 目的：本项目此前在 README 里断言「训练数据只有上证50ETF 单一标的，泛化到个股新闻会明显打折」，
> 但**一直没有实测数据支撑**。本实验用一份**完全独立**的中文财经新闻数据集补上了这个缺口，
> 并顺带回答另一个问题：**换一个域训练，能不能得到更好的模型？**

## 一、数据

| 数据集 | 来源 | 条数 | 测试集 | 文本形态 | 许可 |
|---|---|---|---|---|---|
| **股吧标题** | `HikasaHana/eastmoney_guba_title` | 10,646 | 2,130 | 散户口语，平均 **20.6 字** | 开源 |
| **财经新闻** | `Kenpache/multilingual-financial-sentiment-v2`（FLAME，中文子集） | 14,680 | 2,936 | 媒体书面，平均 **29.1 字** | CC BY-NC 4.0 |

**FLAME 数据集的三个关键特性：**
1. **标注视角天然对齐** —— FLAME 的核心设计是「按本国投资者视角标注」。中文子集即
   "中国投资者怎么看这条新闻"，与股吧场景的情绪口径一致（一般数据集用"全球投资者"视角）。
2. **零泄漏** —— 与股吧语料**完全无重叠**（严格包含检查 0 命中）；
   与 DAPT 语料（CN-Market-Corpus，2013–2023）**不同源、不同期**（2024–2026）。
3. **需繁转简** —— 数据集混有港台媒体（aastocks / 鉅亨網 / Yahoo HK / RTHK），
   实测 **5,752 条（38.7%）为繁体**，已用 `zhconv` 统一转简体。

构建脚本：`ml/prepare_flame_dataset.py`（繁转简 + 标签映射 + 噪声过滤 + 8:2 分层切分，可复现）。

## 二、主结果：跨域对照矩阵

四个模型构成一张 **2×2 对照**（底座 × 数据域），可以同时回答两个问题：
「换域训练有没有用」和「DAPT 有没有用」。

**Accuracy**（对角线 = 同域，非对角线 = 跨域）

| 底座 \ 数据 → 模型 | 股吧测试集 (2,130) | 新闻测试集 (2,936) |
|---|---|---|
| `bert-base-chinese` + 股吧（`lora_guba`） | **0.7460** | 0.5562 |
| `dapt_bert` + 股吧（`lora_dapt`） | 0.7446 | 0.5725 |
| `bert-base-chinese` + 新闻（`lora_flame`） | 0.5549 | 0.8273 |
| `dapt_bert` + 新闻（`lora_dapt_flame`） | 0.5592 | **0.8290** |

**Macro-F1**

| 底座 \ 数据 → 模型 | 股吧测试集 | 新闻测试集 |
|---|---|---|
| `bert-base-chinese` + 股吧（`lora_guba`） | **0.7417** | 0.5594 |
| `dapt_bert` + 股吧（`lora_dapt`） | 0.7408 | 0.5754 |
| `bert-base-chinese` + 新闻（`lora_flame`） | 0.5063 | 0.8074 |
| `dapt_bert` + 新闻（`lora_dapt_flame`） | 0.5189 | **0.8075** |

**跨域掉点：**

| 迁移方向 | 同域 Acc | 跨域 Acc | 掉点 |
|---|---|---|---|
| 股吧 → 新闻 | 0.7460 | 0.5562 | **−19.0 pt** |
| 新闻 → 股吧 | 0.8273 | 0.5549 | **−27.2 pt** |

> 参考基线：股吧测试集多数类（中性）占 40.9%，新闻测试集多数类（看涨）占 49.3%。
> 跨域分数 0.55～0.57 **仅略高于"全猜多数类"**，说明跨域后模型信息量大幅衰减。

### 2.1 两条支线的 DAPT 增益（对称验证）

把「底座」当自变量，两条数据支线各有一组对照：

| 数据域 | 无 DAPT | 有 DAPT | Δ Accuracy | Δ Macro-F1 |
|---|---|---|---|---|
| 股吧（同域） | 0.7460 | 0.7446 | **−0.14 pt** | **−0.09 pt** |
| 新闻（同域） | 0.8273 | 0.8290 | **+0.17 pt** | **+0.01 pt** |

**结论：DAPT 在两条支线上都没有产生有意义的增益。** 新闻支线看似"涨了"，但 +0.17 pt 的
Accuracy 提升伴随 Macro-F1 只动 +0.01 pt，且单类 F1 变化全部 <0.002 —— 同属随机波动量级。
两个方向的符号相反本身也说明这是噪声，而不是稳定的正向收益（若 DAPT 真有效，符号应当一致）。

## 三、逐类明细

### 同域（对角线）

| 模型 → 测试集 | 看跌 F1 | 看涨 F1 | 中性 F1 |
|---|---|---|---|
| 股吧模型 → 股吧 | 0.677 | 0.768 | 0.780 |
| DAPT 股吧模型 → 股吧 | 0.676 | 0.767 | 0.779 |
| 新闻模型 → 新闻 | 0.845 | 0.887 | 0.691 |
| DAPT 新闻模型 → 新闻 | 0.830 | 0.896 | 0.696 |

同域时，**股吧域的短板是「看跌」（≈0.68）**（讽刺/反问噪声多），
而**新闻域的短板是「中性」（≈0.69）**（中性样本被误判为有倾向）。
两条支线上 DAPT 版本与前版的逐类差异均 **< 0.017**，且方向不一致。

### 跨域（非对角线）

| 模型 → 测试集 | 看跌 P / R | 看涨 P / R | 中性 P / R | Acc |
|---|---|---|---|---|
| 股吧模型 → 新闻 | 0.668 / 0.504 | 0.797 / **0.469** | **0.387** / 0.761 | 0.5562 |
| DAPT 股吧模型 → 新闻 | — / 0.514 | — / 0.468 | — / 0.765 | 0.5725 |
| 新闻模型 → 股吧 | 0.674 / **0.197** | 0.682 / 0.513 | 0.500 / **0.848** | 0.5549 |
| DAPT 新闻模型 → 股吧 | 0.677 / 0.242 | 0.671 / 0.495 | 0.505 / 0.838 | 0.5592 |

## 四、关键观察

1. **跨域时两个模型都塌向「中性」** —— 这是本次实验最一致的发现：
   - 股吧模型看新闻：中性 **precision 仅 0.387**、recall 却高达 0.761 → 大量新闻被塞进"中性"，
     真实"看涨"只召回 **46.9%**。
   - 新闻模型看股吧：中性 recall **0.848**，而"看跌"召回崩到 **0.197**（近乎完全失效）。
   - 这与关键词规则基线的失败模式**完全一致**（基线也是 75.3% 判中性）。
     **「域不匹配 → 退化成中性引擎」是这个任务的稳定失效模式**，与模型是否用神经网络无关。

2. **迁移是不对称的：股吧 → 新闻 比 新闻 → 股吧 更容易。**
   掉点 −19.0 pt vs −27.2 pt；Macro-F1 掉 0.5594 vs 0.5063。
   合理解释：股吧口语表达更极端、更依赖圈内黑话（"绿了""打爆空""一字板"），
   新闻模型完全没学过，所以新闻 → 股吧 损失更大；反之新闻是规范书面语，股吧模型多少能沾上。

3. **新闻域内部更容易学** —— 新闻模型同域 Acc 0.8273，明显高于股吧模型的 0.7460。
   原因：① 训练数据更多（11,744 vs 8,516）；② 新闻标题由记者撰写，标注口径更一致；
   ③ 股吧数据本身含较多讽刺/噪声样本（此前数据质检已发现）。

4. **跨域分数（0.55～0.57）几乎不区分模型** —— 四个模型在"对方的域"上表现彼此接近，
   都只是略强于多数类基线。这说明**跨域表现主要由域差距决定，而非源域模型的绝对强弱**。

5. **DAPT 在两条支线上都是"无效变量"** —— 这条 2×2 对照是本报告最强的证据：
   如果 DAPT 真的注入了金融域知识，它应当**同时**提升股吧支线和新闻支线（符号一致）。
   实测却是一个 −0.14 pt、一个 +0.17 pt，**符号相反、幅度都在噪声内**。
   → DAPT 的作用既没有跨域迁移，也没有同域增益，最合理的解释是它**改变的是语料统计分布
   （MLM loss 2.23→1.59，即"换口音"），而不是下游任务所需的判别性表征**。

## 五、结论

1. **README 里那句"泛化到个股新闻会明显打折"得到了实测支持**：掉 **19 个百分点**，
   指标从 0.746 降到 0.556，已接近"全猜多数类"的水准。该断言由*推测*升级为*实证*。
2. **换域训练能显著提升该域表现**：新闻模型在本域达到 Acc 0.8273 / Macro-F1 0.8074，
   比股吧模型在股吧域（0.7460 / 0.7417）还高。**如果能拿到目标域标注数据，换域训练的收益远大于调参。**
3. **但跨域不能靠"换模型"解决**：新闻模型在股吧域反而略低于股吧模型（0.5549 vs 0.5562），
   说明**没有哪个单一模型能同时覆盖两个域**。工程上应按业务场景选模型，
   或做多域联合训练 / 域适配。
4. **DAPT 环节经两条支线独立验证，均无增益** —— 股吧支线 −0.14 pt、新闻支线 +0.17 pt，
   符号相反且全在噪声内。本项目的 DAPT 应如实定位为**流程完整性演示**，
   而非效果提升手段；若要真正见效，需要**域匹配的语料**（口语体）+ **更大的预训练强度**
   （当前 1 epoch / 2,560 万 token 对已充分预训练的 BERT 而言偏轻）。

## 六、复现命令

```bash
cd ml

# 1. 构建 FLAME 中文数据集（繁转简 + 分层切分）
python prepare_flame_dataset.py

# 2. 训练新闻域 LoRA（超参与 lora_guba 完全一致，只换数据）
.venv/Scripts/python.exe train_lora.py --base models/bert-base-chinese \
  --data data/flame_zh_all.csv --out models/lora_flame \
  --epochs 5 --batch_size 32 --lr 5e-4 --lora_r 8 --lora_alpha 16 --merge

# 2b. 换成 DAPT 底座再训一遍（对照：DAPT 有没有用）
.venv/Scripts/python.exe train_lora.py --base models/dapt_bert \
  --data data/flame_zh_all.csv --out models/lora_dapt_flame \
  --epochs 5 --batch_size 32 --lr 5e-4 --lora_r 8 --lora_alpha 16 --merge

# 3. 跑跨域矩阵
.venv/Scripts/python.exe eval_cross_domain.py \
  --model "股吧模型=models/lora_guba/merged" \
  --model "DAPT股吧模型=models/lora_dapt/merged" \
  --model "新闻模型=models/lora_flame/merged" \
  --model "DAPT新闻模型=models/lora_dapt_flame/merged" \
  --data "股吧测试集=data/guba_title_all.csv" \
  --data "新闻测试集=data/flame_zh_all.csv" \
  --split test --out out/cross_domain_matrix.json
```

原始结果见 `ml/out/cross_domain_matrix.json`（三模型版，含逐类 precision/recall/F1）
与 `ml/out/cross_domain_matrix_dapt_flame.json`（`lora_dapt_flame` 单独评测）。
